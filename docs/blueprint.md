# **App Name**: StudyZen

## Core Features:

- Task List: Display tasks with deadlines and priority levels in a clear, organized list.
- Pomodoro Timer: Implement a Pomodoro timer with customizable work and break intervals.
- AI Study Planner: Provide AI-driven study suggestions based on task deadlines and subjects, acting as a tool to assist with study planning.

## Style Guidelines:

- Primary color: #5F8B4C for a calming and focused environment.
- Secondary color: #FFDDAB for a soft, approachable feel.
- Accent: #FFA725 to highlight important actions and elements.
- Clean, modern layout with a focus on readability and ease of use.
- Use simple, intuitive icons to represent tasks, subjects, and features.
- Subtle animations and transitions to enhance user experience and provide feedback.
